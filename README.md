# JOSCR DB（joscr-db）

**コンテンツ別リハビリ・マッピングデータベース — ベータ版**  

> 「好き」を、回復の入口に。
> アニメ・ゲーム・プラモデルなどのコンテンツが、どのような身体機能・認知機能・参加へのアプローチになり得るかを整理・検索するためのデータベースです。

## これは何か

JOSCR DB は、日本オタク＆サブカルチャーリハビリテーション研究会（JOSCR）が開発している、**コンテンツとリハビリテーションの対応関係を検索できるデータベース**のフロントエンドアプリです。

アニメを観る、ゲームをプレイする、プラモデルを組む——こうした活動に含まれる身体的・認知的・社会的な要素を整理し、リハビリテーション専門職や当事者・家族が「この活動はどんな機能や参加につながりうるか」を考えるための参考資料として使えることを目指しています。

現在は**ベータ版**としてプレビュー公開中です。データ・機能ともに開発途中です。

### 「処方箋」という言葉について

本プロジェクトでの「処方箋」は、**JOSCRのコンセプトを表す比喩**です。医師が交付する処方箋や、医療行為としての処方を意味しません。本データベースの情報に基づいて治療内容を決定・変更しないでください。

## JOSCRにおける位置づけ

JOSCRは、サブカルチャー・趣味文化とリハビリテーションを接続する実践者・研究者コミュニティです。JOSCR DB は、定例会・講演・noteでの発信と並ぶ、コミュニティの知見を構造化して共有するための柱のひとつです。

## Therabbyとの違い

姉妹プロジェクトに [Therabby](https://therabby.com/)（作業療法士がつくる臨床アプリ・評価教材・業務支援ツールのポートフォリオ）がありますが、**別ブランド・別目的**です。

| | JOSCR DB（本リポジトリ） | Therabby |
|---|---|---|
| 性格 | コンテンツ×リハの知識データベース | ブラウザで動く試作アプリ・教材群 |
| 主体 | JOSCR（研究会・コミュニティ） | 個人（作業療法士）のポートフォリオ |
| 扱うもの | アニメ・ゲーム・プラモ等の活動分析情報 | 評価補助・活動課題・業務支援のアプリ |

## 想定利用者

- リハビリテーション専門職（作業療法士・理学療法士・言語聴覚士など）が、対象者の「好き」を活動に取り入れる手がかりを探すとき
- 学生・教育者が、活動分析の教材・例として使うとき
- 当事者・家族が、自分の趣味とリハビリの関係を考える入口として使うとき
- JOSCR会員が、定例会・研究のための情報整理に使うとき

## データの扱い

- 本アプリに**個人を特定できる情報（氏名・ID・年齢・診断名など）の入力欄はありません**
- 閲覧・検索の内容がサーバーに保存・送信されることはありません（ホスティング由来の一般的なアクセスログを除く）
- 収録データは、JOSCRメンバーによる活動分析・文献・実践知に基づく整理です

## 使わないこと（このデータベースが目的としないこと）

- 診断、または診断の補助
- 臨床判断の自動化
- 標準化された評価・検査の置き換え
- 治療効果の判定、および特定のコンテンツ視聴・プレイによる治療効果の保証
- 退院可否・運転可否・復職可否などの能力判定
- 実際の処方・医療行為（「処方箋」は比喩です）
- 個人健康情報の収集・管理

掲載情報は参考資料です。実際の臨床での活動選択は、専門職が対象者の状態・嗜好・安全性を確認したうえで判断してください。

## ローカル実行方法

```bash
git clone https://github.com/1toc/joscr-db.git
cd joscr-db
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください（Viteのデフォルトポート）。

```bash
# プロダクションビルド
npm run build
npm run preview
```
